# Образцы заявлений

**Дата актуализации:** 08.08.2026
**Источник:** внутренний регламент компании, составлено в соответствии с ТК РФ

## Заявление на отпуск

```
Администратору ресторана «Вкусный Дом» (точка №___)
от [Ф.И.О., должность]

Заявление

Прошу предоставить мне ежегодный оплачиваемый отпуск
с [дата начала] по [дата окончания] на [количество] календарных дней.

[дата подачи]                                    [подпись]
```

## Заявление на увольнение по собственному желанию

```
Администратору ресторана «Вкусный Дом» (точка №___)
от [Ф.И.О., должность]

Заявление

Прошу расторгнуть трудовой договор по моей инициативе (по собственному
желанию) с [дата увольнения], в соответствии со ст. 80 ТК РФ.

[дата подачи]                                    [подпись]
```

*Если вы находитесь на испытательном сроке — срок предупреждения сокращён
до 3 дней (ч. 4 ст. 71 ТК РФ), см. `испытательный_срок.md`.*

## Заявление на отгул

```
Администратору ресторана «Вкусный Дом» (точка №___)
от [Ф.И.О., должность]

Заявление

Прошу предоставить мне отгул [дата] за счёт [неиспользованных дней отпуска /
без сохранения заработной платы / в качестве компенсации за переработку —
нужное указать].

[дата подачи]                                    [подпись]
```

## Куда подавать

Заполненное заявление передайте администратору точки лично или через
HR-менеджера. Электронный формат подачи (через корпоративный чат/почту)
уточняйте у HR — правила могут отличаться по точкам.
