# Дресс-код и внешний вид

**Дата актуализации:** 08.08.2026
**Источник:** внутренний регламент компании

## Общие требования

- форменная одежда сети «Вкусный Дом» выдаётся при трудоустройстве —
  комплект включает рубашку/футболку с логотипом, фартук, головной убор;
- форма должна быть чистой и выглаженной перед каждой сменой;
- обувь — закрытая, устойчивая, нескользящая подошва (обязательно для кухни).

## Для персонала кухни

- головной убор, полностью закрывающий волосы — обязательно;
- отсутствие украшений на руках (кольца, браслеты) во время работы с продуктами;
- аккуратно подстриженные ногти, без лака.

## Для персонала зала (официанты, бармены)

- опрятная причёска, при длинных волосах — собраны;
- минимальный, неброский макияж и аксессуары;
- бейдж с именем — на видном месте.

## Гигиена

- обязательное мытьё рук перед сменой, после перерыва, после контакта
  с деньгами или уборкой;
- при простудных заболеваниях с симптомами (кашель, насморк) — сообщить
  администратору, работа с продуктами при таких симптомах не допускается.

## Куда обращаться

Если форма не подошла по размеру или требует замены — к администратору точки.
